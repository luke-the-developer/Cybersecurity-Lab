# Cybersecurity-Learning-Journal
Welcome to my cybersecurity learning journal.

This repository will track my progress in cybersecurity through practical labs, technical research,, ethical hacking exercises, programming and security research.

# Aim
- Prepare for future cybersecurity research tasks and investigations within academia and industry

# Objectives
- Progress practical cybersecurity skills through authorised labs
- Document my learning from TryHackMe and other training platforms
- Improve understanding of networking, Linux, Windows and security tools
- Advance programming and scripting tools
- Produce clear technical and evidence-based analytical reports

# Areas of Study
- TryHackMe: Learning pathways, rooms and lab write ups
- Ethical Hacking: Recce and security fundamentals
- Penetration testing: Authorised testing methodologies and reporting
- Networking: TCP/IP and protocols, network security
- Linux and Windows: Operating systems and commands
- Programming: C++ and other languages
- Security research: Technical notes tools and investigations

# Related projects/Labs
A separate project follows my isolated VirtualBox environment focused on malware analysis and investigation alongside practical research. 

# Research approach
Each completed exercise and piece of work will incorporate the following:

## Lab Journal
- Title
- Learning Goals
- Key lab notes
- Key commands
- What I Did
- What I could do better
- Key Learning Outcomes

## Security research Reports
- Title
- Executive Summary
- Situation Analysis (What, when, where, how, why)
- Methodology
- Tactics, Techniques and Procedures (TTPs)
- Key Findings and supporting Evidence
- Assessment and Future Outlook

# Ethical Use
All of the practical exercises I undertake are intended for educational purposes and are conducted in authorised environments. Sensitive information, credentials and restricted challenge solutions will not be published.
